# Codex Relay

Read [AGENTS.md](AGENTS.md) for repository instructions. For a user request to install this repository, follow [INSTALL.md](INSTALL.md) through verification. Use Bun directly when available; Node is also supported. Do not run a build or package installation.

For a request to delegate and follow through, use the installed Skill's `codex_supervise` workflow. The current Claude conversation supervises a separate Codex execution chat. Verify current identity with installed CLI `host` in this session's shell for every MCP setup; shared MCP startup identity can be stale. Pass only supported supervisor identity fields, not the full host output. Prefer an already enabled live channel; do not launch a parallel resume writer to this active session or automatically enable development-channel trust. Require verified Fast-disabled state for the whole channel-supervisor session; resume workers disable Fast for the restored session at process startup. Ordinary messages inherit session settings.

# Commit attribution

- Do not add a `Co-Authored-By` trailer identifying Claude, Anthropic, or any Claude model to any Git commit message.
- Do not add equivalent Claude authorship or "generated by Claude" attribution elsewhere in commit messages.
- Preserve the repository's configured human author and committer identity.
- Apply these rules to new commits, amended commits, and rewritten commits.
